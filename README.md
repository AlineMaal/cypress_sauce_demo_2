\# Swag Labs (Saucedemo) 
 Cypress Automated Test Suite A comprehensive end-to-end (E2E) automated test suite for the [Swag Labs] web application, built using \*\*Cypress\*\* and structured with the \*\*Page Object Model (POM)\*\* design pattern.
 
  --- ## 📌 Project Overview This project automates core user journeys on Swag Labs, including authentication, product catalog interaction, cart management, sorting, and end-to-end checkout.
